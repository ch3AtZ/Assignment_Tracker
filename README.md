ASSIGNMENT TRACKER ASSIGNMENT 

Frontend -> React JS
Backend -> Fast API
DATABASE -> SQLITE 

JUST go to the BASE FOLDER in the Terminal (Assignment_Tracker) 

For the frontend run the command -> npx start --prefix frontend 
For the backend run the command -> uvicorn backend.main:app --reload --port 8000

Run in the incognito mode as sometimes the file upload doesnt work. 

New database is created when run first , so create credentials for both student and teacher in the signup section and then login to view or create assignments.
